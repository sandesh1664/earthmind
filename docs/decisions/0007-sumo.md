# ADR 0007: pinned headless SUMO in the worker

Status: accepted for M01; execution evidence belongs in verification.md.

Install Debian Bookworm's native ARM64 `sumo` package at
`1.15.0+dfsg-1+deb12u1`, with matching `traci==1.15.0` and `sumolib==1.15.0`.
This uses a supported packaged engine instead of emulation. Debian may include
GUI-related libraries, but the application invokes only headless SUMO and
netconvert. CUDA and an X server are not required.

The worker builds a tiny explicitly synthetic network with netconvert, starts
SUMO through TraCI, steps the simulation with a fixed bound, and parses actual
output XML. Capability reporting requires a fresh verified worker record; it
does not infer runtime availability from installed Python modules.

SUMO never runs inside a FastAPI request handler. The fixture proves runtime
compatibility and is not a Dubai traffic scenario or predictive claim.

References: [SUMO Linux installation](https://sumo.dlr.de/docs/Installing/Linux_Build.html)
and [official Python TraCI interface](https://sumo.dlr.de/docs/TraCI/Interfacing_TraCI_from_Python.html).
